## 生平掠影

尸佼，战国鲁人（一说晋人），商鞅之客、谋士，鞅被诛后逃入蜀，著《尸子》二十篇。全书「兼儒墨、合名法」，杂采诸家而归于治道，汉唐间广被征引。其论「砺剑不如砺身」「居则视其所亲……足以观人」，既重进取教化，又重修身守常，是杂家「一体两面」的先声。

## 核心格言

### 格言1

- **原文**：教不厌，所以治人也。
- **出处**：《尸子》
- **译文**：教人不厌倦，是用来治理百姓的。
- **一面解读**：进取面——教化是治国之本。避世面：与「不言之教」相照。
- **标签**：`进取` `治国`

### 格言2

- **原文**：今人皆知砺其剑，而弗知砺其身。
- **出处**：《尸子》
- **译文**：如今人们都知道磨砺自己的剑，却不知道磨砺自身。
- **一面解读**：避世面——修身为本，是道家贵己。进取面：砺身之德胜于砺剑之利。
- **标签**：`避世` `修身`

### 格言3

- **原文**：车唯恐地之不坚也，舟唯恐水之不深也。
- **出处**：《尸子》
- **译文**：车子只怕地不坚实，船只怕水不够深。
- **一面解读**：转化面——进取面：善用者先求可托之资。避世面：顺势借力，是道家「因」。
- **标签**：`转化` `形势`

### 格言4

- **原文**：有其器，则以人之难为易。
- **出处**：《尸子》
- **译文**：有了器具，就能把别人的难事当成易事。
- **一面解读**：进取面——善借器借势，则可化难为易。避世面：借助自然，近于「假于物」。
- **标签**：`进取` `形势`

### 格言5

- **原文**：故曾子曰：父母爱之，喜而不忘；父母恶之，惧而无咎。
- **出处**：《尸子》
- **译文**：曾子说：父母爱我，我高兴而不忘本分；父母厌恶我，我戒惧而不获罪。
- **一面解读**：避世面——孝在修身自省，是立身之道。进取面：顺逆皆成其孝，是处变之德。
- **标签**：`避世` `修身`

### 格言6

- **原文**：夫比粟商贾，比财烈士，比义。
- **出处**：《尸子》
- **译文**：商贾比的是粟米，烈士比的是节义。
- **一面解读**：进取面——各以其道相较，烈士竞义。避世面：比义而不比财，是操守。
- **标签**：`进取` `治国`

### 格言7

- **原文**：人君贵于一国而不达于天下，天子贵于一世而不达于后世，惟德行与天地相弊也。
- **出处**：《尸子》
- **译文**：国君显贵于一国却不能通达天下，天子显贵于一世却不能通达后世，只有德行与天地一样传之久远。
- **一面解读**：转化面——进取面：权位有尽，唯德不朽。避世面：与「金玉满堂莫之能守」，德为至宝。
- **标签**：`转化` `治国` `修身`

### 格言8

- **原文**：所谓良人者，良其行也。
- **出处**：《尸子》
- **译文**：所谓好人，是好在他的品行。
- **一面解读**：避世面——重行不重名。进取面：察人以行。
- **标签**：`避世` `修身`

### 格言9

- **原文**：居则视其所亲，富则视其所与，达则视其所举，穷则视其所不为，贫则视其所不取，此五者足以观矣。
- **出处**：《尸子》
- **译文**：闲居时看他亲近谁，富有时看他结交谁，显达时看他推举谁，穷困时看他不做什么，贫贱时看他不取什么，这五点足以观察一个人。
- **一面解读**：进取面——识人五法，是治国用人之要。避世面：观人于穷达取舍，见其操守。
- **标签**：`进取` `修身` `治国`

### 格言10

- **原文**：土积成岳，则楩楠豫章生焉；水积成川，则吞舟之鱼生焉。
- **出处**：《尸子》
- **译文**：土堆积成山，就有楩楠豫章这样的良材生出；水汇聚成川，就有吞舟的大鱼生出。
- **一面解读**：避世面——厚积而后大，是蓄养之道。进取面：积善积德，厚德载物。
- **标签**：`避世` `归根`

### 格言11

- **原文**：夫茧舍而不治，则腐蠹而弃，使女工缫之以为美锦，大君服而朝之。
- **出处**：《尸子》
- **译文**：蚕茧放着不加工，就成了腐蠹而被丢弃；让女工缫丝织成美锦，君王就穿着它接受朝拜。
- **一面解读**：转化面——进取面：璞玉须琢、人才须教。避世面：物待工而后成，人待道而后贤。
- **标签**：`转化` `治国` `修身`

### 格言12

- **原文**：舍而不治，则成腐蠹；使贤者教之以为世士，则天下诸侯莫敢不敬。
- **出处**：《尸子》
- **译文**：放着不治就成腐蠹；让贤者教导他成为世士，那么天下诸侯没有不敬的。
- **一面解读**：进取面——教化成就人才。避世面：教化为本，近于不言之教。
- **标签**：`进取` `治国`

### 格言13

- **原文**：子路，卞之野人；子贡，卫之贾人；颜涿聚，盗也，孔子教之，皆为显士。
- **出处**：《尸子》
- **译文**：子路是卞地的野人，子贡是卫国的商人，颜涿聚是盗贼，孔子教导他们，都成了显达之士。
- **一面解读**：进取面——教化可化凡为贤。避世面：不弃人，是「无弃人」。
- **标签**：`进取` `治国`

### 格言14

- **原文**：爱恶亲疏废兴穷达，皆可以成义，有其器也。
- **出处**：《尸子》
- **译文**：爱恶、亲疏、废兴、穷达，都可以成就义行，因为有其凭借。
- **一面解读**：转化面——进取面：顺逆皆可为成事之资。避世面：穷达不移，是道家守常。
- **标签**：`转化` `修身`

### 格言15

- **原文**：有其器则以人之难为易，夫道以人之难为易也。
- **出处**：《尸子》
- **译文**：有了凭借就能化人之难为易，道正是把人之难变易的。
- **一面解读**：转化面——进取面：借器借势，以难为易。避世面：体道则事易，是道家之智。
- **标签**：`转化` `无为`

### 格言16

- **原文**：夫贱之工人施巧，人主服而朝也。
- **出处**：《尸子》
- **译文**：卑贱的工匠施展巧艺，人主穿着它的成果接受朝拜。
- **一面解读**：转化面——进取面：用人之巧则享其成。避世面：不贱工巧，近于「善用人者为之下」。
- **标签**：`转化` `治国`

### 格言17

- **原文**：爵列者，德行之舍也。
- **出处**：《尸子》
- **译文**：爵位，是德行的客舍。
- **一面解读**：避世面——爵位为德之寄，德为本、爵为末，是道家重本。进取面：以爵赏德，赏不虚设。
- **标签**：`避世` `修身`

### 格言18

- **原文**：良其行而贵其心。
- **出处**：《尸子》
- **译文**：认为他的品行优良、他的心地可贵。
- **一面解读**：避世面——重德不重爵。进取面：察人贵在行与心。
- **标签**：`避世` `修身`

### 格言19

- **原文**：君亲而近之，至敬以逊；貌而疏之，敬无怨。
- **出处**：《尸子》
- **译文**：君主亲近你，要以恭敬谦逊来表达敬意；君主疏远你，也要恭敬而不抱怨。
- **一面解读**：避世面——处亲疏皆守敬，是立身之道。进取面：不以疏远而失敬。
- **标签**：`避世` `修身`

### 格言20

- **原文**：自娱于櫽括之中，直己而不直人。
- **出处**：《尸子》
- **译文**：在规矩绳墨之中自得其乐，端正自己而不苛求别人。
- **一面解读**：避世面——正己而不责人，是道家修身。进取面：律己宽人则众服。
- **标签**：`避世` `修身`

## 后世评注与关联

- **《尸子》**：战国杂家，原书散佚，今存辑本，四库入子部杂家。
- **与老子对照**：「惟德行与天地相弊」同于老子不朽之德；「爱恶亲疏皆可以成义」近道家守常。
- **与兵家对照**：尸佼佐商鞅，其「砺身」之喻通于治军驭众。
