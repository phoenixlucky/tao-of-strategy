## 生平掠影

子华子，旧题周人程本（字子华），晋人，一说战国时隐者。著《子华子》十篇，四库入子部杂家。全书以「道德为指归，仁义为经纪」，言中和化生、全生贵生、务全其生而不亡其所有，兼论精诚治国。其说以「道立于一」「因其然」为宗，是先秦道家「全生」「归根」一路的少见文本。

## 核心格言

### 格言1

- **原文**：中和玄同，万物化生。
- **出处**：《子华子》
- **译文**：中和玄同，万物由此化生。
- **一面解读**：避世面——中和玄同是生化之源。进取面：阴阳和则事成。
- **标签**：`避世` `玄同` `阴阳相生`

### 格言2

- **原文**：故全生者为上，亏生次之，死次之，迫斯为下矣。
- **出处**：《子华子》
- **译文**：所以保全生命为上，亏损生命次之，死再次之，迫生为下。
- **一面解读**：避世面——贵生全生，是道家。进取面：保身而后可以为事。
- **标签**：`避世` `修身`

### 格言3

- **原文**：辱莫大于不义，不义者迫生也。
- **出处**：《子华子》
- **译文**：耻辱没有比不义更大的，不义就是迫生。
- **一面解读**：避世面——守义即全生。进取面：义不可失。
- **标签**：`避世` `修身`

### 格言4

- **原文**：故曰迫生不如死。
- **出处**：《子华子》
- **译文**：所以说，迫生不如死。
- **一面解读**：避世面——守节重于偷生。进取面：将士有死节。
- **标签**：`避世` `修身`

### 格言5

- **原文**：类同则形同，形同则气同，气同则知识同矣。
- **出处**：《子华子》
- **译文**：同类则形同，形同则气同，气同则智识相同。
- **一面解读**：避世面——同类相感，是道家自然。进取面：物以类聚，同类可召。
- **标签**：`避世` `玄同`

### 格言6

- **原文**：类异则形异，形异则气异，气异则知识异矣。
- **出处**：《子华子》
- **译文**：异类则形异，形异则气异，气异则智识相异。
- **一面解读**：避世面——明类之辨。进取面：知类则知人。
- **标签**：`避世` `玄同`

### 格言7

- **原文**：夫是之谓万化原。
- **出处**：《子华子》
- **译文**：这就叫万化的本源。
- **一面解读**：避世面——万化有本。进取面：握本御末。
- **标签**：`避世` `归根`

### 格言8

- **原文**：故道立于一，而万物之变也。
- **出处**：《子华子》
- **译文**：所以道立于「一」，而万物随之变化。
- **一面解读**：避世面——道一而万变。进取面：执一御万。
- **标签**：`避世` `归根`

### 格言9

- **原文**：古之知道者务全其生，务全其生者不亡其所有也。
- **出处**：《子华子》
- **译文**：古时懂道的人致力于保全生命，致力于全生的人不丧失自己所拥有的。
- **一面解读**：避世面——全生守有。进取面：守其根本。
- **标签**：`避世` `修身`

### 格言10

- **原文**：不亡其所有者，道之守也；道之守者，神之舍也。
- **出处**：《子华子》
- **译文**：不丧失其所有，是守道；守道，是神的居所。
- **一面解读**：避世面——守道养神。进取面：神定则明。
- **标签**：`避世` `修身`

### 格言11

- **原文**：所谓全生者，六欲皆得其宜也。
- **出处**：《子华子》
- **译文**：所谓全生，是六欲都各得其宜。
- **一面解读**：避世面——节欲而得宜。进取面：欲得其宜则不相害。
- **标签**：`避世` `修身` `知足`

### 格言12

- **原文**：所谓迫生者，六欲莫得其宜也。
- **出处**：《子华子》
- **译文**：所谓迫生，是六欲都不得其宜。
- **一面解读**：避世面——纵欲则迫生。进取面：失宜则乱。
- **标签**：`避世` `知足`

### 格言13

- **原文**：目见所甚不欲，不如无见。
- **出处**：《子华子》
- **译文**：眼看极不想要的东西，不如不看。
- **一面解读**：避世面——闭目塞听以养神。进取面：择所见以定心。
- **标签**：`避世` `修身`

### 格言14

- **原文**：直言者，直以情贡也；曲言者，假以指喻也。
- **出处**：《子华子》
- **译文**：直言之言，是径直以实情相告；曲言之言，是借比喻来指事。
- **一面解读**：避世面——明言说之体。进取面：游说当辨直曲。
- **标签**：`避世` `修身`

### 格言15

- **原文**：七十九代之君，法制不一，号令不齐，而俱王于天下。
- **出处**：《子华子》
- **译文**：七十九代的君主，法制不一、号令不齐，却都称王于天下。
- **一面解读**：进取面：王天下不必同一法度。避世面：各有其道。
- **标签**：`进取` `治国`

### 格言16

- **原文**：精诚不白，则无以王矣。
- **出处**：《子华子》
- **译文**：精诚不能昭著，就无法称王天下。
- **一面解读**：转化面——进取面：精诚是王业之本。避世面：诚为道基。
- **标签**：`转化` `治国` `修身`

### 格言17

- **原文**：是以欲治之君，将以有为于是者，必先正其本术，定其精而不摇，保其诚而弗亏。
- **出处**：《子华子》
- **译文**：所以想治理好国家的君主，凡将有所作为，必先端正根本之术，稳固其精而不动摇，保持其诚而不亏损。
- **一面解读**：转化面——进取面：正本而后治。避世面：守诚养精。
- **标签**：`转化` `治国` `修身`

### 格言18

- **原文**：物类相动，焱本相应，孰究其所以来，谁使其所以然，因其然也。
- **出处**：《子华子》
- **译文**：物类相互感动，焱本相互感应，谁能追究它从何而来、谁使它如此？只是顺其自然罢了。
- **一面解读**：避世面——因其自然，是道家核心。进取面：知其所然而因之。
- **标签**：`避世` `归根`

### 格言19

- **原文**：其亏弥甚，则其尊弥薄。
- **出处**：《子华子》
- **译文**：亏损越厉害，其所尊重的就越薄。
- **一面解读**：避世面——亏生则失尊。进取面：损己则失本。
- **标签**：`避世` `修身`

### 格言20

- **原文**：夫人之大常，生而少壮，转而为衰老，转而为死亡。
- **出处**：《子华子》
- **译文**：人的常理，生而少壮，转为衰老，转为死亡。
- **一面解读**：避世面——生死自然，是道家。进取面：知生死则不惧。
- **标签**：`避世` `归根`

## 后世评注与关联

- **《子华子》**：旧题周程本撰，或出后人依托，四库入子部杂家。
- **与庄子对照**：「全生为上」「迫生不如死」近《让王》《养生主》贵生之意。
- **与老子对照**：「道立于一」「中和玄同」「因其然」皆本老子抱一、玄同、自然之旨。
